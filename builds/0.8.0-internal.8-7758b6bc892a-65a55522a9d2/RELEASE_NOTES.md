### 0.8.0-internal.6 မှ ပြောင်းလဲမှုများ

- **FLY cockpit** ကို စာမျက်နှာအကျယ် 39% ခန့်နှင့် ဘယ် column အမြင့် 65.5% ခန့်ထား၍ မြေပုံအတွက် နေရာပိုပေးထားသည်။ HUD အချိုးအစားကို ထိန်းထားပြီး splitter နှစ်ခုဖြင့် ဆက်ညှိနိုင်သည်။
- **3D မြေပုံ** သည် ပြောင်းလဲသည့်အခါ redraw လုပ်ပြီး terrain နှင့် ရုပ်ပုံများကို ပြန်သုံးသည်။ GPS data ဝင်သည့်ကြား ယာဉ်ပုံနှင့် ကင်မရာ ရွေ့လျားမှုကို ချောမွေ့စွာ ပြသည်။ **3D → ⋯ → Render quality** တွင် **Auto / Performance / Full detail** ရွေးနိုင်သည်။ **Map details** တွင် render resolution နှင့် နောက်ဆုံး frame အချိန်ကို ကြည့်နိုင်သည်။
- **Rover / Boat** အတွက် 2D map icon နှင့် 3D model ပါသည်။ GPS fix မရသေးချိန်တွင် model preview ကို ကြည့်နိုင်သည်။
- **Notifications** တွင် app update အသစ်နှင့် ဖြည့်စရာကျန်သော flight record များကို ပြပြီး နှိပ်လိုက်လျှင် သက်ဆိုင်ရာနေရာသို့ ရောက်သည်။ ဖတ်ပြီး/မဖတ်ရသေး အခြေအနေကို သိမ်းထားသည်။ **Mark all as read** ကို ပိုမြင်သာအောင်ပြင်ပြီး **×** မှ panel ပိတ်နိုင်သည်။

App စဖွင့်ချိန် အင်တာနက်ရပြီး update အသစ်တွေ့လျှင် စစ်ဆေး၊ download၊ install လုပ်ပြီး ပြန်ဖွင့်သည်။ `0.8.0-internal.5` နှင့် အဟောင်းမှ တင်ရာတွင် app နှင့် updater ပိတ်ပြီး Setup.exe ဖြင့် update လုပ်ပါ။
