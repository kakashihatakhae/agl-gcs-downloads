# AGL Planner 0.8.0-internal.23 — Windows x64

Windows 10/11 x64 နှင့် .NET Framework 4.7.2 သို့မဟုတ် ပိုသစ်သော version လိုအပ်ပါတယ်။

## Install လုပ်ပုံ

[Windows Setup.exe ရယူရန်](https://github.com/kakashihatakhae/agl-gcs-downloads/releases/download/v0.8.0-internal.23/AGL-Planner-0.8.0-internal.23-Windows-x64-Setup.exe) · [Portable ZIP](https://github.com/kakashihatakhae/agl-gcs-downloads/releases/download/v0.8.0-internal.23/AGL-Planner-0.8.0-internal.23-Windows-x64.zip)

1. လက်ရှိ mission နဲ့ record တွေကို သိမ်းပြီး AGL Planner ပိတ်ပါ။
2. Setup.exe ကို ဖွင့်ပြီး install သို့မဟုတ် update လုပ်ပါ။
3. Start Menu မှ AGL Planner ကို ဖွင့်ပြီး **INFO** မှာ `0.8.0-internal.23` ပေါ်တာကို စစ်ပါ။

Portable ZIP သုံးရင် folder အသစ်ထဲ ဖိုင်အားလုံးဖြည်ပြီး `AGL-Planner-Windows-x64/AGL Planner.exe` ကို ဖွင့်ပါ။

## FLY နဲ့ 3D Map

**FLY → 3D → Pop out** ကနေ 3D Map ကို သီးသန့်ဖွင့်ပါ။ ညာဘက်အပေါ်က **Wind** မှာ လေအမြန်နှုန်းနဲ့ လာရာအရပ်ကို ကြည့်နိုင်ပါတယ်။ **Dock back** နဲ့ FLY ထဲ ပြန်ထည့်နိုင်ပါတယ်။

App ရုတ်တရက်ပိတ်သွားရင် **Recover record** ကနေ မပြီးသေးတဲ့ flight record နဲ့ သိမ်းထားတဲ့ logs ကို ပြန်ဖွင့်နိုင်ပါတယ်။
