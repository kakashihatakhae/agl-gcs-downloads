## [0.6.0-internal.21] - 2026-11-03

- PLAN Terrain Profile ကို cockpit Flight Mode ကဲ့သို့ dark glass material ပြောင်းပါသည်။ မြေပုံအောက်ပိုင်းပေါ်တွင် ထွင်းဖောက်မြင်ရသော tint၊ အပေါ်ဘက် reflection နှင့် light rim ပါးပါးဖြင့် ပြပါသည်။ Graph၊ value၊ warning အရောင်များကို ထိန်းထားပါသည်။

- ဤ version သည် Git preview ဖြစ်ပြီး published update channel ကို မပြောင်းပါ။
