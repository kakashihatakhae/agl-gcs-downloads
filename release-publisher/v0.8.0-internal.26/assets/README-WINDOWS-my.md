# AGL Planner 0.8.0-internal.26 — Windows x64

Windows 10/11 x64 နှင့် .NET Framework 4.7.2 သို့မဟုတ် ပိုသစ်သော version လိုအပ်ပါတယ်။

## Install လုပ်ပုံ

[Windows Setup.exe ရယူရန်](https://github.com/kakashihatakhae/agl-gcs-downloads/releases/download/v0.8.0-internal.26/AGL-Planner-0.8.0-internal.26-Windows-x64-Setup.exe) · [Portable ZIP](https://github.com/kakashihatakhae/agl-gcs-downloads/releases/download/v0.8.0-internal.26/AGL-Planner-0.8.0-internal.26-Windows-x64.zip)

1. လက်ရှိ mission နဲ့ flight record တွေကို သိမ်းပြီး AGL Planner ပိတ်ပါ။
2. Setup.exe ကို ဖွင့်ပြီး install သို့မဟုတ် update လုပ်ပါ။
3. Start Menu ကနေ AGL Planner ဖွင့်ပြီး **INFO** မှာ `0.8.0-internal.26` ပေါ်တာကို စစ်ပါ။

Portable ZIP သုံးရင် folder အသစ်ထဲ ဖိုင်အားလုံးဖြည်ပြီး `AGL-Planner-Windows-x64/AGL Planner.exe` ကို ဖွင့်ပါ။

## FPV View နဲ့ Review Flight

- **FPV View** မှာ **ALT** နဲ့ **HOME** ကြား မြေပုံအသေးကနေ Home နဲ့ waypoint တွေကို ကြည့်နိုင်ပါတယ်။ **Edit OSD → Elements** မှာ **RCIN1** နဲ့ **RCIN2** ကို ရွေးပြီး **Save layout** နှိပ်ပါ။
- **Flight Records** ထဲမှာ flight တစ်ခုရွေးပြီး **Review Flight** နှိပ်ပါ။ သိမ်းထားတဲ့ telemetry ကို မြေပုံပေါ်မှာ ပြန်ကြည့်နိုင်ပြီး warning ကို နှိပ်ရင် ဖြစ်ခဲ့တဲ့အချိန်ကို တန်းရောက်ပါတယ်။
